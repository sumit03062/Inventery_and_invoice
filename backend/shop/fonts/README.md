# Invoice font

Noto Sans Devanagari, sourced from the Google Fonts `ofl/notosansdevanagari` directory on 30 September 2026. The variable font was instantiated at its default axis values using fontTools. See OFL.txt for the bundled SIL Open Font License.

ReportLab uses HarfBuzz shaping for Hindi/Devanagari and embedded Latin glyphs. Other Indian scripts need additional fonts and separate visual validation.
